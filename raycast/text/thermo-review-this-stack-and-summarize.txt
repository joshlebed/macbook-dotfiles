let's get reviews for the latest versions of all open PRs:

1. get the latest review prompt template from notion doc: https://app.notion.com/p/4050494456f681aa897bf75cdc764e97
2. get PR metadata for all PRs you are responsible for:
```
for n in <n1> <n2> ...; do
  gh pr view $n --repo <owner>/<repo> --json number,title,author \
    -q '[.number,.author.name,.author.login,.title]|@tsv' || echo "$n FAILED"
done
```
3. `create_task` per PR, all in parallel:
   - environmentName: `niteshift`
   - projectIds: `["3c08b59d-0f99-45ab-a4fb-0fb64eb52f8d"]`
   - model: `gpt-6.1-sol`
   - effortLevel: `high`
   - speed: `fast`
   - taskName `#<n> (<first token of author.name, else author.login>): <title>`
   - prompt: the filled reviewer template
if there is an error starting the task, retry once with
   - model: `claude-opus-5-5`
   - effortLevel: `high`
   - speed: `fast`
4. find and dismiss all other review tasks for your open PRs, if any exist. use `list_tasks` per PR, all in parallel:
   - nameContains: `#<n> (<first token of author.name, else author.login>):` (the title of the PR may have changed)
5. Reply: table of PR link | reviewer link (copy the `url` create_task returns) | PR title
6. Poll those reviewer tasks every 3 minutes until they all finish. then read each review. for each finding in each review, verify the finding individually. do not assume that it is correct. then make a recommendation as to whether we should act on the finding or not. don't implement any code changes yet.
at the end of your writeup on the full analysis of the reviews, write a section about the big picture. are there any signals/smells that some of our implementation should be rearchitected or rethought? are there any patterns that could be improved? it may be cheaper to rebuild or redesign now than to build this the wrong way and have to make bigger changes later after this is merged. if there is any possibility that we could land on a better design, explore those options and present them with an explanation of the trade offs.
after the big picture analysis, give a summary of your recommendation. should we focus on the big picture architecture or design? if the big picture seems right, then what are the most important findings or issues that we should address?
